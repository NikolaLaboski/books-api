#  Books API  
A simple and clean REST API built with **Node.js**, **Express**, and **Prisma ORM** using **SQLite** as the database.  
Perfect starter backend project demonstrating CRUD operations, database migrations, and an organized API structure.

---

##  Features

- Create, Read, Update, Delete books
- Express.js REST endpoints
- Prisma ORM data modeling & migrations
- SQLite lightweight database
- Clean code structure with comments
- Ready for deployment or expansion

---

##  Technologies Used

- **Node.js**
- **Express.js**
- **Prisma ORM**
- **SQLite**
- **Nodemon** (for development)
